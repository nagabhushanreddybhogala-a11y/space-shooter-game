# Space Shooter Game

A beginner-friendly 2D arcade game made with HTML, CSS and JavaScript.

## How to play
- Click **START GAME**.
- Move the spaceship using **Left / Right Arrow** or **A / D**.
- Press **SPACE** to shoot.
- Destroy the pink enemies to earn 10 points each.
- Avoid enemies reaching your spaceship or the bottom of the screen.
- Click **PLAY AGAIN** to restart.

## Run locally
1. Download or clone this repository.
2. Open `index.html` in a modern web browser.
3. No installation or external libraries are required.

## Files
- `index.html` - page structure
- `style.css` - game styling
- `script.js` - game mechanics and drawing

## Built with
HTML5 Canvas, CSS3 and vanilla JavaScript.
